Cartographie

Solution d'entreprise complète conçue pour cartographier, inventorier et rechercher l'ensemble du parc de serveurs et des applications hébergées. Développée avec l'écosystème .NET et Blazor, l'application comprend la modélisation de base de données relationnelle, le développement d'une API REST performante, des batchs d'automatisation et de synchronisation, ainsi qu'une interface web réactive pour la recherche multicritère et l'analyse d'impact.
